# Skill 来源与许可证

本包提供 86 个可导入的 Skill 目录，对应原库的 89 项。其中 19 个目录的 `SKILL.md` 与原库逐字节相同，其余目录采用下列固定版本的公开上游文件。每个目录随附上游许可证和适用的版权声明，可单独导入。飞书三份参考文档中的示例资源标识用占位符表示。

飞书的会议相关能力已由上游整合到 `lark-meeting`，覆盖原库中的 `lark-vc`、`lark-vc-agent`、`lark-minutes` 和 `lark-note`。使用时需要安装飞书 CLI 并完成账号授权。
